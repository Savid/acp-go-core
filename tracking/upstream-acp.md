# Upstream ACP Watchlist

Outstanding adoption decisions. Current behavior belongs in the contract and
registry; resolved items belong in Git. Recheck the linked sources before
acting and replace this snapshot when they change.

Protocol status verified **2026-10-03** against the published
[RFD updates](https://agentclientprotocol.com/rfds/updates) and
[v2 proposal](https://agentclientprotocol.com/rfds/v2/overview): ACP v1
remains the family's protocol; v2 is an active draft.

| Watch | Family impact | Action trigger |
|---|---|---|
| [ACP v2](https://agentclientprotocol.com/rfds/v2/overview) | Prompt lifecycle, updates, restore, permissions, content, and capabilities across every sibling and host | Stable protocol and usable Go SDK support; scope one coordinated cutover. |
| [Go SDK](https://github.com/coder/acp-go-sdk/releases) | Verified 2026-10-03: latest release remains v0.13.5 (2026-06-02); generated types and transport behavior lag newer stable protocol fields. | A release implements a needed stable surface or fixes a relevant defect; plan a family update. |
| [Go SDK content marshaling](https://github.com/coder/acp-go-sdk/blob/v0.13.5/types_gen.go#L1473) | Verified 2026-09-14: `ContentBlock.MarshalJSON` drops `_meta` and `annotations` for text and image variants. A Go SDK client therefore loses the image handoff envelope before the request reaches the adapter; embedded calls and correctly encoded ACP frames retain it. | A corrected generated marshaler; verify content metadata round trips, then scope the shared SDK pin update across every sibling and host. |
| [Go SDK capability marshaling](https://github.com/coder/acp-go-sdk/blob/v0.13.5/types_gen.go#L42) | Verified 2026-09-15: `AgentCapabilities.Auth` and `.McpCapabilities` are struct-valued `omitempty` fields and `MarshalJSON` is a plain alias marshal, so `"auth":{}` and `"mcpCapabilities":{}` are on every initialize frame and cannot be omitted. The advertised meaning is unaffected: both decode to the ACP default with every transport false. | Pointer-typed or custom-marshalled capability fields; then scope the shared SDK pin update across every sibling and host. |
| [Go SDK prompt cancellation](https://github.com/coder/acp-go-sdk/blob/v0.13.5/agent_gen.go#L411) | Verified 2026-09-15: `AgentSideConnection` keeps one cancel func per session id and calls the previous one before dispatching a new `session/prompt`, then deletes the entry when that prompt returns. A second prompt therefore cancels the handler context of the in-flight one even when the sibling refuses it with backpressure, and a following `session/cancel` finds no registered context. Every sibling drives its native turn from session-owned cancellation. The high-level client `Prompt` sends both `$/cancel_request` and `session/cancel` when its caller context is cancelled; raw request cancellation alone leaves the native turn running. | A release that refuses or ignores a concurrent `session/prompt` per session rather than superseding it; re-check whether the session-owned cancellation in each prompt handler can be simplified, then scope the shared SDK pin update. |
| [Codex `account/rateLimits/read`](https://github.com/openai/codex/blob/rust-v0.154.0/codex-rs/app-server-protocol/src/protocol/v2/account.rs#L331) | Verified 2026-09-17 on 0.154.0: `GetAccountRateLimitsResponse` carries `rateLimits` and an optional `rateLimitsByLimitId` map; an unauthenticated home and an API-key login both refuse with `-32600`. The Codex account-usage read maps the per-limit map and `ordinaryUsageAllowed` only and does not consume `account/rateLimits/updated`. | A release that changes the snapshot shape, the account variants, or the refusal code; re-verify the Codex mapping and its scripted fake. |
| [Claude Code `get_usage`](https://registry.npmjs.org/@anthropic-ai/claude-code-darwin-arm64/2.1.278) | Source-verified 2026-09-20 in the integrity-checked published package: the experimental control reply carries fixed `rate_limits` members and `model_scoped` windows. `rate_limits_available` can be true with null `rate_limits` when no fetched report is available. `skip_behaviors: true` skips transcript analysis. | A release that changes the request, fixed members, model scopes, quota headers, or setup-token usage access; re-verify the native mapping and its scripted fake. |
| [Subagents proposal](https://github.com/agentclientprotocol/agent-client-protocol/pull/855) | Delegated-agent identity and lifecycle | An accepted protocol shape or a native structured stream supplies facts the adapter can prove. |
| [Mid-turn input](https://github.com/agentclientprotocol/agent-client-protocol/pull/1261) | Host queueing and steering | A stable shape is supported by the native harness and Go SDK. |
| [Image capability proposal](https://github.com/agentclientprotocol/agent-client-protocol/issues/1559) | The family media-envelope advertisement | A stable standard represents the same enforced limits and formats. |
| [Tool call name](https://agentclientprotocol.com/rfds/tool-call-name) | Verified 2026-10-03: Completed since 2026-09-17; the [stable v1 schema](https://agentclientprotocol.com/protocol/v1/schema) includes optional `name` on tool calls and updates. The pinned Go SDK has no corresponding field. | A Go SDK release exposes the stable field; then map native tool names in one coordinated family update. |
| [Session compaction](https://agentclientprotocol.com/rfds/session-compaction) | Verified 2026-10-03: Preview since 2026-09-23 behind `unstable_session_compaction`; native Nanocodex compaction events can supply lifecycle facts. | Stabilization and Go SDK support; prove capability gating, lifecycle ordering, and replay before adoption. |
| [Session notices](https://agentclientprotocol.com/rfds/session-notices) | Verified 2026-10-03: Preview since 2026-09-24 behind `unstable_session_notices`; the surface is live advisory information outside conversation history. | Stabilization and Go SDK support; identify native advisory facts and prove client capability gating. |
| [Nanocodex snapshot recovery](https://github.com/gakonst/nanocodex/blob/ef6e62ef492f5eef3eee17eab6bced9c6b29947e/crates/nanocodex-agent/src/session.rs) | Source-verified 2026-10-03 at `ef6e62e`: native context overflow sets a runtime force-compaction flag that `SessionSnapshot` does not carry. The adapter persists its own mark in the checkpoint sidecar and calls `Nanocodex::compact()` before the next prompt; that compaction runs before prompt acceptance and cannot be cancelled through ACP. | Native snapshot support for forced compaction, or a cancellable compaction admission that can precede a prompt; then drop the adapter mark or move compaction after acceptance, and prove recovery across helper restart. |
| [Nanocodex compacted-turn persistence](https://github.com/gakonst/nanocodex/blob/ef6e62ef492f5eef3eee17eab6bced9c6b29947e/crates/nanocodex-agent/src/rollout/store/writer.rs) | Source-verified 2026-10-03 at `ef6e62e`: a compacted turn persists replacement context instead of response-item rows. Pre-turn replacement output can replay; tool details removed by mid-turn compaction before this write cannot. | Native persistence of visible turn output independently of reduced model context; prove tool and assistant replay after mid-turn compaction and native-state deletion. |

These are triggers to investigate, not claims that upstream has shipped them.
